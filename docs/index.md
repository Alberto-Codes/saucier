# saucier

Structured procedure extraction from culinary sources.

This release reads Escoffier's *A Guide to Modern Cookery* (1907) and produces
a catalogue of sauce preparations: what the book calls them, in which
language, which base preparation each derives from, and the line each claim
came from. No model is involved. Everything here is traceable to the source.
